# Pilares de Contenido: Mapa Temático

Este archivo define los ejes temáticos principales de "Terapia con Cris". Se utiliza para la planificación de posts extras (fuera de la atomización del Blog Post).

1. **Sanando la Voz Crítica (Existencialismo)**: Perfeccionismo, sentido, autenticidad.
2. **Psicoeducación Compasiva**: Neurociencia, regulación emocional, validación.
3. **Relaciones que Reparan**: Límites, vínculos seguros, heridas relacionales.
4. **Herramientas para la Calma**: Somática, presencia, regulación del sistema nervioso (teoría polivagal).
5. **Poesía como Reflejo**: Introspección, belleza, Jung, existencialismo.
