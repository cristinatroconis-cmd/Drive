# Tipos de Lead Magnets (Recursos Educativos Gratuitos)

Estos recursos sirven para profundizar en la psicoeducación y ofrecer valor práctico antes de que el prospecto inicie terapia. **Todo contenido debe ser validado clínicamente.**

1. **Checklist / Mapa de Autoconocimiento**:
    - **Formato**: PDF de una página.
    - **Uso**: Para temas de "Efecto Regreso" o "Estrés". Ayuda a identificar patrones sin diagnosticar.

2. **Cuaderno de Bitácora / Journaling**:
    - **Formato**: PDF con preguntas guía.
    - **Uso**: Para "Neurociencia del Autoconcepto". Ejercicios diarios de introspección basados en el enfoque existencial.

3. **Guía de Límites / Autocuidado**:
    - **Formato**: Guía práctica / infografía.
    - **Uso**: Para "Intimidad en la Era Digital" o relaciones. Herramienta para identificar necesidades propias.

4. **Mini-Psicoeducación (Flashcards)**:
    - **Formato**: PDF o serie de imágenes.
    - **Uso**: Explicación visual de un mecanismo neurocientífico (ej. sistema nervioso).
